# Field

## Purpose

Composes label, control, description, and error for accessible forms.

## When to use

- Any labelled input with optional help or error text

## Anatomy

- `Field` — wrapper grid
- `FieldLabel` — label
- `FieldDescription` — help text
- `FieldError` — error with `role="alert"`

## Theming

Uses spacing scale and `muted-foreground`, `destructive` tokens.

## Change policy

See registry entry `field`.
